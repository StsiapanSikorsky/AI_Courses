# Конспект по курсу IBA AI Engineering

**Модель** - это матрицы чисел которые при размышлении перемножаются между собой, умножение осуществляет GPU видеокарты. Для корректной работы модели вся она целиком должна вместиться в VRAM (память видеокарты). Также каждый контекст разговора включается как KV-cache в VRAM, из-за этого чем длиннее разговор, тем больше нужно памяти VRAM   

**Данные** - набор необработанных фактов, цифр или информации используемых для анализа, принятия обоснованных решений и развития передовых технологий   

## Основные сокращения:   
1) **AA Index** - индекс интеллекта модели   
2) **CNN (Convolutional Neural Network)** - сверточные нейросети, используются в области компьютерного зрения. Использует фильтры определенного размера (прим: 3х3 пикселя) которые скользят по картинке и ищут локальные признаки. Работа слоев CNN:
   - Первый слой ищет простые вещи: линии, края, углы, точки   
   - Следующий слой комбинирует линии в более сложные формы: круги, прямоугольники и текстуры  
   - Глубокие слои собирают из форм целые объекты  
   - Последний слой принимает финальное решение  
Применяется в: распознование лиц, медицинская диагностика, автопилоты, обработка видео, генерация изображений.  
3) **RNN (Recurrent Neural Network)** - рекуррентная нейронная сеть, создана для работы с последовательными данными где важен порядок элементов. Когда сеть обрабатывает элемент она использует текущий вход и то, что запомнила из прошлого (т.е. новое состояние это функция от предыдущего состояния + текущего входа).  
Применяется для: обработка и перевод текста, распознование речи, генерация речи, временные ряды (прогноз погоды, курса, акций), музыка (генерация мелодий, распознование нот)  
Проблема: RNN обладает короткой памятью, в связи с чем были разработаны LSTM и GRU архитектуры   
5) **LSTM (Long Short - Team Memory) - долгая краткосрочная модель, усовершенствованная версия RNN созданная для того, чтобы помнить информацию очень долго    
6) **GRU (Gated Recurrent Unit)** - упрощенная более быстрая альтернатива LSTM с меньшим количеством параметров  
7) **GAN (Generative Adversarial Network)** - генеративно состязательная сеть. Суть: две нейросети соревнуются друг с другом для создания реалистичных данных.  
Процесс обучения:  
- генератор получает случайный шум на входе и создает изображение/звук/текст   
- дискриминатор получает два изображения (реальное из датасета и поддельное от генератора)  
- дискриминатор пытается угадать где правда а где фейк  
- генератор учится создавать все более реалистичные фейки для обмана дискриминатора  
- соревнуются пока генератор не начнет создавать неотличимые от реальных данные  
8) **BLUE metrix (Bilingual Evaluation Understudy)** - автоматическая мерика для оценки качества машинного перевода   
9) **MLM (Masked Language Modeling)** - моделирование маскированного языка. Метод самообучения в обработке естественного языка (NLP), который используется для предварительного обучения LLM. Модель учится понимать язык восстанавливая случайно скрытые слова в предложении    
10) **NSP (Next Sentence Prediction** - метод обучения основанный на предсказании следующего предложения    
11) **PEFT (Parameter Efficient Fine Tuning)** - набор методов, позволяющих адаптировать огромные языковые модели под конкретные задачи, обучая небольшое количество конкретных параметров, вместо переобучения модели целиком. Технология позволяет запускать обучение на потребительском оборудовании, делает модели модульными и ускоряет процесс    
12) **LoRA (Low Rank Adaptation)** - метод PEFT позволяющий дообучать LLM с минимальными затратами. Вместо обновления всех миллиардов параметров предобученной модели, к некоторым слоям добавляются небольшие матрицы, которые и обучаются во время обучения   
13) **QLoRA (Quantization LoRA)** - усовершенствованная LoRA позволяющая дообучать модели к примеру 70B на видеокарте с 24ГБ памяти  
14) **RLHF (Reinforcement Learning from Human Feedback)** - метод обучения с подкреплением на основе обратной связи от человека. Модель учится выдавать те ответы, которые нравятся людям   
15) **PPO (Proximal Policy Optimization** - оптимизация ближайшей политики. Популярный алгоритм обучения с подкреплением. Позволяет обновлять политику модели маленькими контролируемыми шагами для улучшения ее поведения, при этом не ломая что она умеет (тонкая настройка)    
16) **RAG (Retrieval Augmented Generation)** - архитектурный подход генерации с дополненным извлечением. Подключает внешнюю базу знаний к LLM перед тем, как она сгенерирует ответ. Т.е. пологаемся не только на знания зашитые в веса модели, но и позволяем заглянуть модели в документы, базы знаний или интернет в момент ответа, чтобы взять оттуда актуальную и точную информацию.  
Процесс RAG состоит из 2 этапов:   
  - Создание эмбеддингов (индексация): все документы в базе заний (файлы, веб страницы и т.д.) разбиваются на небольшие чанки. Каждый фрагмент преобразуется в векторное представление (эмбеддинг) с помощью модели энкодера и сохраняется в векторной БД. Когда пользователь задает вопрос, его текст преобразуется в эмбеддинг с помощью той же модели энкодера. Векторная БД ищит фрагменты чьи эмбеддинги наиболее близки к эмбеддингу вопроса. Находится наиболее релевантный фрагмент докуммента.
  - Генерация: найденная информация подается в LLM для синтеза ответа   
17) ETL (Extract Transform and Load) - процесс сбора и подготовки данных. Включает в себя сбор данных из разных источников, их очистку, преобразование и хранение в новом месте. После данного этапа ML инженер создает модели ML    


## Этапы внедрения AI в бизнес процессы:   
0) Формулировка бизнес задачи  
1) Оценка данных которыми располагает компания    
2) Объединение данных в центральный источник (снижает необходимость работать с несколькими БД)    
3) Подготовка данных (очистка данных, удаление экстремальных значений, фильтрация ненужных значений)   
4) Проверка данных на основе экспертизы эксперта каждой категории   
5) Разделения данных для обучения и тестирования   
6) Создание модели машинного обучения (используем все актуальные и доступные фреймворки)   
7) Выбираем метод фильтрации данных   
8) Проверка корректности модели (этап оценки модели)   
9) Развертывание модели в продакшене   

## Инструменты ML:   
1) Pandas library - библиотека для анализа и обработки данных. Используется для анализа, визуализации и подготовки данных   
2) NumPy - библиотека предоставляющая математические функции, генераторы случайных чисел и процедуры линейной алгебры для распределенных графических процессов или вычислительных платформ на базе графических   процессов. Обеспечивает базовую поддержку машинного обучения   
3) Matplotlib library - библиотека для визуализации данных и построения графиков   
4) Scikit-learn - библиотека предоставляющая широкий спектр контролируемых и неконтролируемых алгоритмов обучения для линейной регрессии. Используется для построения классических моделей ML   
5) TensorFlow - библиотека для численных вычислений и крупномасштабного машинного обучения   
6) Keras - библиотека для глубокого обучения для реализации нейросетей   
7) PyTorch - библиотека для приложений глубокого обучения и NLP   
8) OpenCV - библиотека компьютерного зрения    
9) Языки программирования: Python, R, Scala, Java, JS   
10) PostgreSQL   
11) Hadoop - хранение и пакетная обработка больших объемов данных   
12) Spark - распределенная платформа обработки данных в памяти для обработки больших данных в реальном времени   
13) Apache Kafka - распределенная потоковая платформа для создания конвейеров больших данных и выполнения аналитики в реальном времени   
14) NLTK - библиотека для обработки текста, токинизации и стемминга   
15) TextBlob - библиотека для теггирирования частей речи, извлечения существительных, анализа настроений и перевода   
16) Stanza - библиотека NLP для теггирирования частей речи, распознавания именованных сущностей и анлиза зависимостей
